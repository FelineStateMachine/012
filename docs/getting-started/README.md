# Getting started

012 is a spreadsheet for the terminal: Google Sheets' behavior inside
the grid, Lotus 1-2-3's look around it.

![Typing a small budget, pointing at cells in a formula, and watching totals recalculate](../media/first-steps.gif)

1. [Install and run](install.md) 012.
2. Type into cells as in Sheets: text, numbers, `$1,200`, `12%`, dates,
   and formulas starting with `=` ([formulas](../formulas/README.md)).
   Enter and Tab accept and move on.
3. [The screen](the-screen.md) says what's going on: the mode indicator,
   the formula bar and the context line, which shows the keys that apply.
4. F1 lists every shortcut, F10 or Alt+letter opens the menus, and
   Ctrl+K searches every command. The [keys](../reference/keys.md) page
   has them all, and the vim keymap.
